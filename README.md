# Mi habitación

Aplicación privada y local. Los datos se guardan únicamente en el navegador.

## Ejecutar localmente

1. Instala Node.js 22.13 o posterior.
2. Ejecuta `npm install` en esta carpeta.
3. Ejecuta `npm run dev` y abre la dirección local indicada.

Para comprobar producción: `npm run build` y después `npm start`.
